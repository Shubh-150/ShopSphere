# ShopSphere — Smart E-Commerce Platform

ShopSphere is a responsive frontend e-commerce demo built as part of the SWYNEX Technologies Frontend Development Internship.

## Features

* Responsive product catalog
* Product data fetched from Fake Store API
* Live product search
* Category filtering
* Price and rating sorting
* Shopping cart with quantity controls
* Wishlist functionality
* Local Storage persistence
* Dark mode
* Loading indicators and API error handling
* Product and shopping analytics

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Fake Store API
* Git and GitHub
* Vercel

## How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension.
4. Make sure you have an internet connection to load the product data.

## API

Product data is fetched from https://fakestoreapi.com/products.

## Project Limitations

This is a frontend educational demo. It does not process payments, place real orders, or provide backend authentication.
